| Folder | Contents |

| [game/](game/README.md) | The game's own texts in languages it does not ship (Catalan, Galician, Basque, Turkish, Vietnamese, Ukrainian, Indonesian, Arabic, Hindi) |
| [syllables/](syllables/README.md) | For the scripts the game and the menu cannot shape (Hindi): each syllable our texts use and the private-use character it is written with |
